链式订阅工作台

机场节点中转 → SOCKS5 落地出口 → YAML 与订阅链接

01 · 配置线路 本地生成

需为 Clash / Mihomo 格式订阅。软件导入配置后自动拉取节点，每小时更新；这里不通过第三方转换站读取订阅。

导入说明与兼容性

适用于 Mihomo / Clash Meta 内核，如 Clash Verge Rev、FlClash。启用配置并使用规则模式，「出口选择」选「SOCKS5落地」，「机场中转」选择机场节点。默认公网流量全部走落地出口，局域网直连；禁用 UDP 443 以避免不支持 UDP 的落地影响 QUIC。SOCKS5 使用普通 TCP，不会因为端口为 443 就开启 TLS。

如果「机场中转」只有 COMPATIBLE，说明订阅尚未加载：在软件中更新代理集合，检查订阅地址、网络和 Clash 格式；本工具不会把加载失败当作连接成功。

02 · 上传 GitHub，生成 URL

请使用公开仓库。上传后配置中的订阅地址及 SOCKS5 密码会公开。Token 仅发往 GitHub API，不写入配置，也不保存到浏览器。
首次使用：如何准备 GitHub
  1. 先创建公开仓库，勾选添加 README，以创建 main 分支。
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  3. 选择目标仓库，将 Repository permissions → Contents 设为 Read and write，生成 Token。
  4. 填写用户名、仓库、分支和 Token，点击上传。不要把 Token 发给别人。

手动模式：先下载 YAML，在 GitHub 上传到填写的路径；拼接只生成地址，不代表文件已上传。

03 · 结果

等待填写。配置生成不需要 GitHub Token；生成在线 URL 需要先上传文件。

CDN 首次同步可能有延迟；Raw 无法访问时可尝试 CDN。GitHub 链接能否下载仍取决于本机网络。
